# Terminal GIF Player 🖥️🎞️

在终端中用 **ANSI 24-bit TrueColor** + **半块字符 (▀)** 播放 GIF 动画。

> 兼容 Windows Terminal / iTerm2 / gnome-terminal / Konsole 等现代终端。

## 快速开始

```bash
# 1. 安装依赖
pip install Pillow

# 2. 运行

```

## 核心特性

### 画质优化

- **ANSI 24-bit TrueColor** — 每个像素独立 RGB 色彩 (16.7M 色)，远超传统 256 色方案
- **半块字符技术** — 使用 `▀` (U+2580) 字符，上半部=前景色，下半部=背景色，一个字符位置承载 **两个像素**，垂直分辨率翻倍

### 流畅播放

- 使用 `\033[H` 重置光标到左上角，**不清屏**，消除闪烁感
- 读取 GIF 每帧自带的 `duration` 属性控制帧率
- 精确帧计时：每帧扣除渲染耗时后再 sleep，避免帧率漂移
- 预渲染全部帧为 ANSI 字符串，播放时零开销切换

### GIF 兼容性

- 正确处理 GIF 四种 `disposal method`（叠加/替换/恢复背景/恢复前一帧）
- 透明区域合成为黑色底色

### 自动缩放

- 画面超出终端高度时自动按比例缩小
- 网格模式下超出终端时逐步缩小单元格（每次 ×0.85），直到放得下

## 用法

```
python gif_player.py [-h] [-w WIDTH] [-g WxH] [--once] [gif]
```

| 参数 | 说明 |
|------|------|
| `gif` | GIF 文件路径。省略则进入交互式文件选择器 |
| `-w, --width` | 画面宽度（字符数）。单播放模式=画面宽度；**网格模式=每个单元格宽度**。超出终端时自动缩小 |
| `-g, --grid WxH` | 网格平铺模式。在同一画面中平铺播放多个相同 GIF |
| `--once` | 只播放一次，不循环 |

### 示例

```bash
# === 基础播放 ===
python gif_player.py                        # 交互式选择 GIF 文件
python gif_player.py cat.gif                # 播放 cat.gif
python gif_player.py cat.gif --once         # 只播一次

# === 指定宽度 ===
python gif_player.py cat.gif -w 60          # 画面宽 60 字符

# === 网格模式 ===
python gif_player.py cat.gif -g 2x1         # 2 列 1 行 → 左右并排两个 🐱 🐱
python gif_player.py cat.gif -g 2x2         # 2×2 网格 → 四个 🐱🐱🐱🐱
python gif_player.py cat.gif -g 3x2         # 3×2 网格 → 六个

# === 网格 + 单元格宽度 ===
python gif_player.py cat.gif -g 2x2 -w 40   # 2×2 网格，每格 40 字符宽

# === 所有参数组合 ===
python gif_player.py cat.gif -g 2x1 -w 50 --once
```

### 网格模式自动缩放

以 `-g 2x2` 为例，终端 80×40：

```
1. 初始: cell_w = 80 ÷ 2 = 40 字符
2. 渲染后发现 cell_h × 2 = 25 × 2 = 50 行 > 40 行 ❌
3. 缩小: cell_w = 40 × 0.85 = 34 → 重新渲染
4. cell_h × 2 = 21 × 2 = 42 行 > 40 行 ❌
5. 再缩小: cell_w = 34 × 0.85 = 28 → 重新渲染
6. cell_h × 2 = 18 × 2 = 36 行 ≤ 40 行 ✅  → 开始播放
```

## 技术原理

### 半块字符 (Half-Block)

```
      1 个终端字符位置
      ┌─────────────────┐
      │   前景色像素      │  ← 上方像素 (fg = 前景色)
      │   ▀▀▀▀▀▀▀▀▀▀▀  │
      │   背景色像素      │  ← 下方像素 (bg = 背景色)
      └─────────────────┘

ANSI: \033[38;2;R1;G1;B1m\033[48;2;R2;G2;B2m▀

如果 GIF 高度为 200px，只需要 100 行字符即可完整显示
→ 垂直分辨率翻倍
```

### 无闪烁播放

```python
# ❌ 传统做法：清屏 → 重绘 → 闪烁
os.system('clear')
print(frame)

# ✅ 本方案：只移动光标 → 覆盖绘制 → 无闪烁
sys.stdout.write('\033[H')   # 光标归位
sys.stdout.write(frame)      # 覆盖旧画面
```

### Disposal Method 处理

| Method | 含义 | 处理方式 |
|--------|------|----------|
| 0 | 未指定 | 新画布 + 当前帧 |
| 1 | 不丢弃 | 叠加到累积画布 |
| 2 | 恢复背景 | 黑色画布 + 当前帧 |
| 3 | 恢复前一帧 | 还原 prev_canvas + 当前帧 |
